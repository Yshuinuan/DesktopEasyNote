# 桌面旁白记录器 · 策划案

> **这版改了什么**：v1 首版，从灵感文档收敛成可实施的完整方案。关键变化——输入从「托盘弹小窗」改成「单页备忘录」，旁白口吻定为 ICEY 式，生成从「23:30 / 少于 3 条」改成「次日 07:00 / ≥1 条」，产物定为静默导出 md + 屏底一行提示。

---

## 1. 一句话说清

一个常驻 Windows 托盘的小软件：白天在一个备忘录页里随手记下「干了啥 + 心情」，次日早上让 AI 用 ICEY 那种毒舌旁白的口吻，把昨天讲成一段故事，静默导出成 md。

---

## 2. 背景与目标

来源：灵感文件 `E:\⭐灵感素材库\灵感\2026-11-14-桌面旁白记录器.md`。

- **目的**：证据 —— 这天到底干了啥，别让时间黑洞吞掉。
- **核心体验**：记录时安静，收尾时「开口」（AI 旁白）。
- **口吻**：ICEY 式旁白 —— 毒舌、冷幽默、跟你拌嘴、打破第四面墙。
- **形态**：极简，只有一个记东西的页面，没有历史、没有文档切换、没有查看页面。

目标用户就一个人（你自己），自用，不追求分发给别人。

### 被否掉的方案（记下来，实施别回退）

- 托盘小窗「点开写一条就关」的仪式感输入 → 改成单页备忘录。
- 「少于 3 条 → 今天留白」→ 改成 ≥1 条就生成。
- 当天 23:30 生成 → 改成次日 07:00 生成昨天。
- 手动「说一句」按钮 → 砍掉，只留定时。
- 应用内查看旁白的页面 / 点击跳转看旁白 → 砍掉，直接导出 md。
- 弹窗 / 托盘角标常驻提示 → 改成屏底一行提示，跳出又缩回。
- 周总结旁白、图片导出 → 后续再说，不进首版。

## 3. 核心方案

三块：

1. **记录**：一个备忘录页，白天往里逐行加（写一句 + 右键插入心情 + 保存），存成本地文件。
2. **生成**：次日 07:00 定时，把昨天的记录喂给 DeepSeek，按 ICEY 旁白守则生成 ≤500 字。
3. **产出**：旁白静默导出成 md 文件；生成成功后屏底跳一行提示又缩回。

---

## 4. 规则与流程

### 4.1 一天的定义（跨天边界）

- 「一天」= 当天早上 **06:00** 到次日 **06:00**。
- 凌晨 **0:00–6:00** 写的记录，算**前一天**的。
- 举例：11-15 凌晨 01:50 写的，归入 11-14 这一天（跟灵感文档里那条 01:50 的落法一致）。

### 4.2 记录格式

- 一天一个文件，存 `data/YYYY-MM-DD.md`，文件名用「这天开始的日期」。
- 一行一条，格式：`HH:MM · 内容 · 心情`
  - `HH:MM`：本地时间，自动带上（用户不用自己写）。
  - `内容`：用户写的那句话；「干了啥」和「心里话」混一行，允许写废话。
  - `心情`：六动词之一，**可选**（没选就省略这段）。
- 示例：

  ```
  08:47 · 醒。看了眼时间，又睡了 · 想躲
  11:40 · 泡面，配一个讲时间管理的视频
  16:30 · 便利店，买了冰咖啡，把饭团放回去了 · 走神
  ```

- 心情六动词：**做成了 / 卡住 / 硬撑 / 走神 / 空转 / 想躲**

### 4.3 记录流程

1. 打开软件（托盘左键），进入备忘录页。
2. 底部输入框写一句，可右键 → 插入心情 → 选一个（不选也行）。
3. 点右上角「保存」或按回车。
4. 系统自动带上当前时间戳，写入当天文件，页面列表新增一行。

### 4.4 生成流程（每天一次）

1. 次日 **07:00**（本地时间）触发。
2. 读取「昨天」（已结束的那天）的记录文件。
3. 昨天 **0 条记录** → 静默跳过，不生成、不提示。
4. 昨天 **≥1 条** → 把记录 + 旁白守则喂给 DeepSeek，生成旁白。
5. 旁白写入 `output/YYYY-MM-DD.md`（文件名同记录日期）。
6. 屏底跳一行提示「今天的旁白写好了」，然后缩回消失。

### 4.5 补跑

- 若 07:00 时应用没在运行（关机 / 没开），下次**启动时**检查：`data/` 下所有「已结束」的天（该天 06:00 结束点已过），有记录但缺 `output/` 对应 md 的，逐个补跑生成。

## 5. 旁白守则（ICEY 版，喂给 AI 的）

> 这是给模型的系统提示词核心内容，实施时原样拼进 prompt。

1. 底色用第三人称「他」来讲（像旁白讲主角那样有旁观距离），可以**频繁打破第四面墙**，直接跟「你」拌嘴、吐槽、评价。
2. 有明确人格：毒舌、冷幽默、不耐烦、会吐槽、有脾气；但**不人身攻击**，不往真伤人的方向写（这是你自己的记录，不是敌人）。
3. 它知道自己是一段**会被读到的旁白**，会拿「你正在读它」这件事开涮。
4. 不写「这是有意义 / 充实 / 糟糕的一天」这种盖棺定论的总结；吐槽要落在**具体那件事**上，对事不对人。
5. 幽默靠语气、反差、平静地讲荒唐事，**不靠形容词堆砌**；不写「好笑的是」，直接把荒唐讲出来。
6. **只用记录里出现过的东西**，没记的一个字不许提；时间戳必须来自记录，**不许自造**。
7. 一条一个时间戳打头，像小说分节；收在**台词或一个没收尾的动作**上。
8. **不超过 500 字**。

## 6. 数值与配置

| 项 | 值 | 说明 |
|---|---|---|
| 心情动词 | 做成了 / 卡住 / 硬撑 / 走神 / 空转 / 想躲 | 6 个，固定 |
| 旁白字数上限 | 500 字 | 硬上限 |
| 生成时间 | 次日 07:00 | 本地时间 |
| 一天边界 | 06:00 | 0–6 点归前一天 |
| AI 默认 | baseURL `https://api.deepseek.com`，model `deepseek-chat` | 可配，key 用户填 |
| 毒舌档 | 冷毒舌（写死） | 首版不做档位 UI |

配置存本地（key 等），首版设置弹窗只放 apikey。

## 7. 界面与交互

### 7.1 主窗口（唯一页面）

- 主体：**今天已记的列表**（只读，备忘录式，行尾显示心情小字标签）。
- 底部：一个输入框。
- 右上角两个按钮：**保存**、**设置**。
- 输入框内：**右键 → 插入心情 → 六个动词**，选一个带上（行尾小标签）；不选也行。
- **最小化 = 缩到托盘图标**，关窗口不退出程序。

### 7.2 托盘图标

- **左键点击 = 打开窗口**。
- **右键 = 菜单**：`退出` / `设置key`。

### 7.3 设置弹窗（右上角「设置」或托盘「设置key」打开）

- apikey 输入框 + 「存入」按钮。
- 首版只放 key；时间、毒舌档走默认值。

### 7.4 屏底提示

- 生成成功后，屏幕最底下跳出一行「今天的旁白写好了」，**几秒后向下缩回消失**；不可点、不跳转。

### 7.5 首次启动

- 直接弹设置弹窗，引导填 key。

## 8. 边界与异常

| 情况 | 处理 |
|---|---|
| 昨天 0 条记录 | 静默跳过，不生成、不提示 |
| 凌晨 0–6 点的记录 | 归前一天文件 |
| 没填 key 就生成 | 静默跳过，写本地日志；首次启动强制弹设置引导填 |
| API 调用失败 | 重试 3 次（间隔递增），仍失败则放弃当天、写日志，不打扰用户 |
| 07:00 没在运行 | 下次启动时补跑（见 4.5） |
| 06:00 跨天 | 页面列表清空，开始新的一天（旧的已在文件里） |
| 内容里出现 ` · ` 分隔符 | 解析按「首段=时间、末段若命中六动词=心情、其余拼接=内容」处理 |
| 时区 | 一律按本地时间（Asia/Shanghai），06:00 边界和 07:00 生成都是本地时间 |

## 10. 验收标准

1. 写一句 + 右键选心情 + 保存 → `data/当天.md` 新增一行，格式 `HH:MM · 内容 · 心情`，时间戳为本地时间。
2. 凌晨 01:30 的记录 → 落入「前一天」文件；早上 07:00 的记录 → 落入当天文件。
3. 昨天 ≥1 条 → 07:00 生成 `output/昨天.md`，≤500 字，口吻 ICEY 式，时间戳全部来自记录。
4. 昨天 0 条 → 不生成、不弹提示。
5. 生成成功 → 屏底跳一行提示又缩回。
6. 托盘左键打开窗口，右键菜单含「退出」「设置key」，最小化缩托盘不退出。
7. 首次启动弹设置弹窗，填 key 存入后本地保留。
8. API 失败 → 重试 3 次后放弃，不崩溃，日志可查。
9. 补跑：关机错过 07:00，下次启动自动补生成缺的 md。
